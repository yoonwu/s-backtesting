# 볼스위칭 (Vol-Switching) — TQQQ/SOXL 레짐 스위칭 전략

무한매수법 정밀 조사(2026-07)에서 전 구간 최강으로 나온 전략의 재현 코드.

## 규칙 (전부임)

```
QQQ 종가 > QQQ 200일 이동평균          ← 추세 필터
AND QQQ 20일 실현변동성(연율) < 28%    ← 변동성 필터
→ 두 조건 모두 참이면 TQQQ 100%
→ 하나라도 깨지면 전량 현금
```

- 신호는 하루 1번, 종가 기준으로 계산. 장 마감 무렵 MOC 주문으로 체결(lag=1).
- 공격형 프리셋: MA150 & vol<32% (`--preset aggressive`)
- SOXL 버전: 신호자산을 SOXX(반도체 지수 ETF)로 (`--trade SOXL --signal SOXX`)

## 왜 이 두 필터인가

3배 레버리지 ETF의 손익은 기초지수 방향 × 변동성 드래그로 분해된다.
일수익률 r, 변동성 σ일 때 3x ETF의 장기 성장률은 근사적으로 `3μ − 3σ²` (기초는 `μ − σ²/2`).
**변동성 비용이 기초지수의 6배**로 커지는 게 레버리지의 진짜 가격표다.

- **200MA 필터**: μ<0인 국면(장기 하락)을 잘라낸다. 2000·2008·2022를 밖에서 구경하는 장치.
- **변동성 필터**: μ>0이어도 σ가 크면 3x는 드래그로 녹는다(횡보+고변동 = 최악).
  20일 vol<28%는 "지수가 오르면서 조용한" 국면만 골라 탄다.

두 필터는 서로 다른 실패 모드를 막기 때문에 하나만 쓰는 것보다 강하다.
(200MA 단독: 2015·2018 같은 급변동 구간에서 얻어맞음 / vol 단독: 저변동 하락장에 노출)

## 근거 (mumae-data 리서치 결과 요약)

| 구간 | 볼스위칭(공격형) | TQQQ B&H |
|---|---|---|
| 2010~2026 (강세장) | CAGR 41.6% / MDD −49.8% | 43.6% / −81.7% |
| 1999~2026 (닷컴 포함, 합성) | 28.2% / −62.3% | 2.5% / −100.0% |
| 1985~2026 (풀 사이클, 합성) | 26.0% / −62.3% | 14.1% / −100.0% |

- 워크포워드 4/4 구간 전부에서 무한매수법 계열 압도.
- 파라미터 능선이 넓음: MA150~250 × vol28~35 전부 B&H(장기 14%) 위 → 과최적화 아님.
- 매매 빈도 연 5~6회전 → 비용·세금 내성 좋음.

**약점 (정직하게)**
1. 강세장 단독 구간에선 B&H보다 CAGR 1~2%p 낮다 — 하락장 보험료.
2. V자 반등 초입을 놓친다(변동성이 아직 높아서). 2025-04 관세 폭락 후 반등이 대표 사례.
3. MDD −50~−62%는 여전히 존재. 3x인 이상 어떤 규칙도 이를 못 없앤다.
4. 합성 3x(닷컴 구간)는 상수 드래그 근사라 실제 상품과 오차가 있다.

## 사용법

```bash
# 1) 데이터 받기 (GitHub Actions 러너가 수집 → volswitch/data/에 커밋됨)
#    Actions 탭 → fetch-market-data → Run workflow  (또는 워크플로 파일 푸시 시 자동)
git pull

# 2) 기본 실행 (방어형: MA200, vol<28)
python3 volswitch.py

# 3) 공격형 / SOXL / 구간 지정 / 능선 스캔 / 닷컴 포함 장기
python3 volswitch.py --preset aggressive
python3 volswitch.py --trade SOXL --signal SOXX --preset aggressive
python3 volswitch.py --start 2018-01-01 --end 2022-12-31
python3 volswitch.py --grid
python3 volswitch.py --synthetic --preset aggressive   # QQQ 합성 3x, 1999~

# 4) 보수적 체결 검증 (다음날 종가 체결)
python3 volswitch.py --lag 2
```

의존성: `pip install pandas numpy`

## 실전 운영 체크리스트

1. 매일 장 마감 30분 전, QQQ 현재가로 두 조건 계산 (MA는 그날 종가 근사로 거의 확정).
2. 상태가 바뀌는 날만 MOC(장마감) 주문. 안 바뀌면 아무것도 안 함.
3. 신호가 애매하게 경계에 걸린 날(MA ±0.5% 이내)은 다음날 확정 신호로 처리해도 성과 차이 미미 (lag=2 검증 참조).
4. 백테스트는 리서치 기록이며 투자 자문이 아님.
